# Overtone UI 设计方案 v4 ——「纸带与信号 · Tape & Signal」

> 适用产品：Overtone（泛音）—— 原生 macOS Jellyfin 音乐客户端（SwiftUI，macOS 13+）
> 文档性质：**另一条视觉路线**的完整设计规范（B 方案），与 v3「Liquid Glass」并行供选，不覆盖 v3
> 核心差异：v3 是「数字玻璃」—— 透明、悬浮、氛围光；v4 是「模拟印刷」—— 纸面、墨字、广播红、点线引导
> 信息架构：完全继承 v2 / v3（首页 / 五档断点 / 令牌体系 / 页面骨架不变），**只换视觉语言**

---

## 1. 概念与动机

### 1.1 一句话概念

把界面做成一张**排版精良的音乐小报**：暖纸底、衬线墨字、广播红只给「正在发声的事」，列表用点线引导（leader dots），进度用 VU 段条 —— 像 1970s 电台节目单与黑胶内页，安静、有手感、可触摸。

### 1.2 为什么要有这一套（与 v3 的分工）

| 维度 | v3「Liquid Glass」 | v4「纸带与信号」 |
|---|---|---|
| 气质 | 未来、系统原生、空气感 | 复古、编辑感、纸墨手感 |
| 适合场景 | 跟随 macOS 26 Liquid Glass 潮流的默认皮肤 | 品牌记忆点强烈的「签名皮肤」；长时间阅读列表不疲劳 |
| 实现代价 | 依赖材质 API（26+ / 13–25 回退分支） | **零材质依赖**，纯色 + 1px 描边，任何 macOS 版本表现一致 |
| 性能 | blur 层有预算限制（≤4） | 无 blur，滚动最轻 |
| 深色模式 | 玻璃暗化 | 「夜场」暖黑，天然适合夜间听歌 |

### 1.3 概念三原则

1. **纸墨分离**：一切表面要么是「纸」（暖中性面），要么是「墨」（文字与实心块）。禁止中间态的灰塑料感。
2. **红只属于声音**：信号红（signal red）是全界面唯一的彩色行动色 —— 只出现在播放中、ON AIR、主按钮、当前进度上。静止即墨。
3. **印刷规则代替分割线**：区块之间不用卡片堆叠，用「细线 + 字距标签」（——— 最近添加 ———）与点线引导（……）建立秩序，像报纸版面。

### 1.4 情绪板（文字版）

- 1970s 日本爵士厂牌内页（Three Blind Mice / TBM 的排版）
- BBC 电台节目单 / Radio Times 的表格
- 模拟台机的 VU 表与「ON AIR」灯牌
- 活字印刷的引导点线与小型大写字母标签

## 2. 设计语言

### 2.1 色彩：纸 / 墨 / 信号

三种「物质」构成全部色彩，另有泛音青作辅助色（用于智能列表、同步状态等次级信息）。

| 角色 | 浅色「日场」 | 深色「夜场」 |
|---|---|---|
| 纸 · 画布 canvas | `#F4EEE1` 暖纸 | `#17130E` 浓缩咖啡 |
| 纸 · 页面 sheet | `#FBF7EC` 白纸 | `#201A13` 牛皮纸 |
| 纸 · 凹陷 sunken | `#EDE5D2` | `#17120C` |
| 墨 · 主文字 ink | `#221D16` | `#EFE6D3` |
| 墨 · 次级 ink-2 | `#5F5749` | `#A99C86` |
| 墨 · 三级 ink-3 | `#8B8170` | `#7C7260` |
| 信号红 signal | `#C2402A` | `#E85E3C` |
| 信号红 · 文字用 signal-ink | `#A83420` | `#F07A58` |
| 泛音青 overtone | `#2E6E66` | `#57ADA4` |
| 细线 hairline | `rgba(34,29,22,.16)` | `rgba(239,230,211,.16)` |
| 强线 hairline-strong | `rgba(34,29,22,.32)` | `rgba(239,230,211,.30)` |

规则：
- 品牌面板（登录左栏、播放中大字）**固定反色**：墨底 + 纸字，双主题一致 —— 像报纸的固定版头。
- 不用投影（elevation = 0）。层次全靠：纸/墨反差、1px 细线、字重与字号。唯一例外是 Toast 的「活版压印」硬阴影（§4.8）。
- 强调色在外观设置里仍可换（信号红 / 靛蓝 / 泛音青 / 紫），演示预览支持即时切换。

### 2.2 字体：三套系统各司其职

| 角色 | 字体栈 | 用途 |
|---|---|---|
| 展示衬线 display | `"New York", "Iowan Old Style", Georgia, "Songti SC", "Noto Serif SC", serif` | 页面大标题、专辑名、艺人名、登录品牌字、大数字 |
| 界面无衬线 UI | `-apple-system, "PingFang SC", "Hiragino Sans GB", sans-serif` | 导航、按钮、表单、说明文字 |
| 等宽 mono | `"SF Mono", ui-monospace, Menlo, monospace` + `tabular-nums` | 时长、曲目序号、播放次数、百分比、BPM |

- 中文衬线优先 `Songti SC`（宋体）—— 与「印刷」概念同源，比黑体更「墨」。
- 小型大写标签：11px / 600 / 字距 `.08em` / 大写（中文用全角空格模拟留白），两侧配细线。
- 数字永不跳动：所有会变的数字（时间、次数）一律 mono + tabular-nums。

### 2.3 形状与线

- 圆角：**统一 3px**（控件）/ 封面 2px / 按钮胶囊例外（快速入口用胶囊，半径 full）。v3 的同心圆角体系在此不适用 —— 印刷品没有同心圆。
- 描边：1px hairline 是主要分隔手段；选中态是「墨块填充」而非描边加粗。
- 内文行高：列表行 56pt、表格行 48pt，行间以 hairline 分隔，斑马纹不用。

### 2.4 视觉母题（四个，贯穿全页面）

| 母题 | 形态 | 出现位置 |
|---|---|---|
| **点线引导** | 标题与右侧数值之间的 dotted 延伸线 | 曲目行、Top 10、播放列表、队列 |
| **VU 段条** | 10 段方条，已播 = 信号红，未播 = hairline；正在播放段呼吸闪烁 | 进度条（全局唯一进度形态） |
| **谐波线** | 1.5px 细折线波形（品牌图形） | 登录页、正在播放页背景、空态插画、侧栏 logo |
| **ON AIR 灯牌** | 3px 圆角小红方块 + mono 字「ON AIR」 | 当前播放行、正在播放页、迷你播放条 |

### 2.5 动效（克制，全部 ≤200ms）

- 翻页：页面内容 160ms 淡入 + 上移 4px（`ease-out`）。
- 播放/暂停：VU 段条填充过渡 120ms；当前段 900ms 呼吸（降低动态效果时静止）。
- 无弹簧、无缩放弹跳、无玻璃模糊。尊重系统「减少动态效果」。

## 3. 令牌表（与 Theme.swift 的对应命名）

> 若落地 v4，建议在 Theme.swift 中以 `PaperTokens` 独立枚举承载，与现有玻璃令牌**并存**，由外观设置切换「视觉风格：玻璃 / 纸墨」。

### 3.1 颜色

```
paper.canvas / paper.sheet / paper.sunken
ink.text / ink.text2 / ink.text3 / ink.fill        // ink.fill = 实心墨块
signal.base / signal.ink / signal.tint             // tint = 8% 信号红底
overtone.base / overtone.tint
line.hairline / line.hairlineStrong
```

### 3.2 字号（阶梯与 v3 一致，便于双轨切换）

| 令牌 | 值 | 用途 |
|---|---|---|
| caption | 11/16 · 600 · .08em | 小型大写标签 |
| footnote | 12/16 | 辅助说明 |
| body-sm | 13/18 | 列表次级信息 |
| body | 14/20 | 正文 |
| title4 | 16/24 · 600 | 区块标题 |
| title3 | 18/26 · 600 | 页面标题（衬线） |
| display | 24/30 · 700 衬线 | 专辑名 |
| hero | 34/40 · 700 衬线 | 登录品牌字 / 正在播放曲名 |

### 3.3 间距 / 圆角 / 线

- 间距 4 的倍数：4 / 8 / 12 / 16 / 20 / 24 / 32 / 40。
- 圆角：控件 `r.sm = 3`、封面 `r.cover = 2`、胶囊 `full`。
- 线宽：hairline 1px；ON AIR 指示条 3px；VU 段高 6px。

## 4. 组件库

### 4.1 按钮

| 类型 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| 主按钮 primary | 墨底 `#221D16` + 纸字 | 纸底 + 墨字（反色） | 连接服务器 / 播放 |
| 次按钮 secondary | 纸底 + 1px hairline + 墨字 | 同构 | 随机播放 / 加入队列 |
| 幽灵 ghost | 无底无框，墨-2 字 | 同构 | 查看全部 → |
| 危险 danger | 信号红底 + 白字 | 同构 | 退出登录 |

- 高度 32（常规）/ 28（紧凑）；热区 44；圆角 3；主按钮 hover 墨色加深 8%。

### 4.2 表单控件

- 输入框：纸底（sunken）+ 1px hairline + 圆角 3；聚焦时 hairline-strong + 2px 信号红外环（`box-shadow: 0 0 0 2px signal.tint`，实线不用发光）。
- 开关 switch：32×18 方形轨道（圆角 3），关 = hairline 描边空底，开 = 墨底 + 纸色方钮 14px（**不用胶囊**，保持印刷感）。
- 分段 segmented：纸底容器 + 1px hairline；选中段 = 墨底纸字；圆角 2。

### 4.3 导航

- 侧栏项：高 36，圆角 3；默认 ink-2 字；hover 纸底 sunken；**选中 = 墨块填充 + 纸字 + 左缘 3px 信号红条**。
- 侧栏分组标签：caption 级小型大写 + 两侧细线（「媒体库」「我的列表」）。
- 窄窗图标栏 64pt：仅图标，tooltip = 标签（宽窗不挂）。

### 4.4 列表行（两种）

> **决策记录（2026-10-14，用户裁决）**：列表里的**点线引导已全部撤除**（「横线太多了」）——
> 曲目行 / Top 10 / 播放列表行三处，点线占的那段宽度改成等宽的弹性空白，
> 行几何与「标题弹性 + 艺人定宽列 + 数值列」的对齐关系完全不变；`LeaderDots` 组件本身保留
> （见 `Components/PaperComponents.swift` 的注释）。本节以下描述是该组件的原始设计，
> 其余场景（未来真需要「引导」的目录页 / 点菜单）仍可复用。

**点线行（曲目 / Top10 / 队列）** —— v4 的标志性组件：

```
 3  [封面40] 曲名字体 14/600 …………………… 艺人名        3:42
              ↑ 点线：border-bottom 1px dotted hairline-strong，距基线 -3px
```

- 行高 56（详情表）/ 48（队列）；序号 mono 12；当前播放行：左缘 3px 信号红 + ON Air 徽标 + VU 迷你段条替代时长。
- 桌面表格（资料库列表视图）用对齐列，不用点线 —— 点线是「可变长内容」的引导，定宽表格会双重引导。

### 4.5 VU 段条（进度）

- 结构：10 段 × (段宽 flex-1, 间隔 2px, 高 6px, 圆角 1)。
- 状态：已播段 = 信号红实心；当前段 = 信号红 40% + 呼吸；未播 = hairline 实心。
- 迷你播放条版：段高 4，整条可点击跳转；键盘 ±5s 微调（继承 v3 可访问性）。
- 缓冲/直连态：段序上方 2px 处显示更细的 10 段缓冲条（ink-3，20% 高度）。

### 4.6 封面卡片（「印刷套封」）

- 封面 2px 圆角 + **内描边**（inset 3px，rgba 白 .22 / 黑 .18，模拟封套压框）+ 底部 1px 墨字条（可选）。
- 封面内容是设计资产：扁平色块 + 衬线大字（专辑名首字 / 厂牌名），禁渐变照片感 —— 预览中以 CSS 生成的「唱片内页」式封面示意。
- 网格卡：封面 + 衬线专辑名 14/600 + 艺人 ink-2 12；hover 封面下移 1px（活版按压感）。

### 4.7 区块标签

```
──────────  最近添加  ──────────     排序 ▾
```
- caption 级 + 字距 .08em + 两侧 1px 细线延伸至容器缘；右侧操作（排序/查看全部）跟在细线后。

### 4.8 Toast / 空态 / 骨架

- Toast：墨底纸字 + **2px 右下硬阴影**（`2px 2px 0 hairline-strong`，活版压印）；出现 160ms，3s 消退。
- 空态：谐波线插画 64 + 衬线标题 16/600 + ink-2 说明 13 + 主/幽按钮。
- 骨架：sunken 底 + 谐波线扫过（1200ms 一次，降低动态效果时静止）。

## 8. 可访问性基线

- 对比度（实测值需落地时复核）：浅色 ink/canvas = 13.6:1；signal-ink/paper.sheet = 5.9:1；ink-2/paper.sheet = 6.8:1；深色对应值均 ≥ 4.5:1（正文）/ ≥ 3:1（大字与组件描边）。
- 颜色永不单独承载信息：ON AIR 行同时有红条 + 文字徽标 + VU 段条；同步状态同时有彩色点 + 文字。
- 热区 ≥44×44（继承 v3 的 `hitExpand` 写法）；全部图标按钮 `accessibilityLabel`。
- 键盘：Tab / 空格 / ⌘1–5 / ⌘F / ⌘, / Esc 行为与 v3 完全一致；VU 段条 ±5s。
- 动态字号 xxLarge：衬线标题降级至 title3，点线行右侧数值列允许换行至第二行（行高自适应 +4）。

### 9.1 实现备注（与预览的差异，均为有意取舍）

- 侧栏保持「悬浮纸面板」（四边细线），未做预览里的贴边 + 1px 右细线：贴边要同时改断点宽度计算与
  红黄绿三键定位，超出「只换视觉语言」的范围。
- 详情表 / 队列 / Top10 / 搜索歌曲组用点线行（§4.4「行高 56（详情表）/ 48（队列）」）；资料库列表视图
  用定宽对齐列、**不**用点线（§4.4 末条）。曲目行由 `MusicRow(rowStyle:)` 一个参数切换这两种形态。
- 强调色在纸墨下默认跟随「信号红」（切风格时自动跟随签名色：靛蓝 ↔ 信号红，泛音青 / 紫属用户显式选择不覆盖）；
  切风格会**按目标风格重建色阶**（纸墨色阶 ≠ 玻璃色阶，顺序不能反）。
- 换强调色的落地方式改成了「呈现层换视图身份」：`NSApp.appearance` 往返那套动态色重解析在 macOS 27 上
  已不会让 SwiftUI 重绘内容（改动前的二进制同样如此，属既有缺陷），所以 `MainView` / 登录分支的 `.id`
  现在同时带风格与强调色。
