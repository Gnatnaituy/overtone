# Overtone UI 设计方案 v5 ——「暖阳胶片 · Sunlit Film」

> **状态**：设计规范 + [高保真预览](UI-Redesign-v5-preview.html)，**未落地**（落地路径与代价见 [§9](#9-落地映射未落地)）。
> **定位**：与 v3「Liquid Glass」、v4「纸带与信号」并列的**第三套视觉风格（C 方案）**，共用同一份信息架构、五档断点与快捷键契约。
> **一句话**：把曲库做成一本**晒过太阳的杂志** —— 奶油片基、高对比衬线刊头、照片边缘溢出的光晕；琥珀金只标记「正在发生的事」。

---

## 1. 概念与动机

### 1.1 一句话概念

界面是一张**在午后阳光里摊开的胶片与杂志**：片基是晒太阳晒出暖调的奶油纸，标题是时尚杂志那种高对比衬线（Didot / Bodoni 一脉），封面像刚冲洗出来的照片带着**光晕（halation）**，唯一的彩色行动色是**阳光琥珀金** —— 它只出现在「正在播放、可点击、已选中、已播进度」这四件事上。深色模式不是把浅色压暗，而是**暗房**：琥珀安全灯下的暖光自发光。

### 1.2 为什么要有第三套（与 v3 / v4 的分工）

| 维度 | v3「Liquid Glass」 | v4「纸带与信号」 | **v5「暖阳胶片」** |
|---|---|---|---|
| 气质 | 未来、系统原生、空气感 | 复古、编辑感、纸墨手感 | **温暖、摄影质感、杂志版心** |
| 光 | 靠材质与背光 | **无光**：纯色 + 1px 细线定秩序 | **单一暖光源**：光晕分级 + 暖色柔影 |
| 信息密度 | 中 | **高**（小报：小字号、密表格、点线引导） | **低**（杂志：大留白、大字级差） |
| 字号级差 | 34 ↔ 11（3×） | 34 ↔ 11（3×） | **44 ↔ 10（4.4×）** |
| 数字 | SF Pro | 等宽 tabular | **衬线旧体**（oldstyle），大数字 |
| 形状 | 同心圆角 + 投影 | 3px 硬角、**零投影** | 14–18px 软角 + **暖色柔影** |
| 强调色语义 | 靛蓝 = 品牌 | 信号红 = **声音** | 琥珀金 = **温度 / 交互**；红只给危险 |
| 深色模式 | 玻璃暗化 | 暖黑「夜场」 | **「暗房」**：黑底上的安全灯自发光 |
| 实现代价 | 材质 API（26+ / 13–25 回退分支） | 零材质依赖、零 blur | **零材质依赖**，只用 `box-shadow` 分级 |
| 最适合 | 跟随系统潮流的默认皮肤 | 长时间读列表、白天办公 | 大屏展示、封面驱动浏览、夜间听歌 |

**三套并存的取舍（先说清楚）**：v3/v4 已经是「两套同时构造、切换只换 `Theme.state.active` 引用」的架构，再加一套的**边际成本不在令牌层，而在视图层** —— 全仓有 **148 处 `Theme.isPaper ? 纸墨 : 玻璃` 二值分支**（分布在 20 个文件里），二值三元表达式无法直接容纳第三个值。这是 v5 落地的主要工程量，[§9](#9-落地映射未落地) 给了分阶段方案与「哪些分支必须改」的判据。

**v5 与 v4 都会「暖」**，两者必须靠**四条硬性差异**隔开，否则会互相稀释：

| 硬性差异 | v4 | v5 |
|---|---|---|
| 密度 | 行高 44–48，边距 16–32 | **行高 52–64，边距 20–40，区块间 72** |
| 字号级差 | 34 → 11 | **44 → 10** |
| 圆角 | 3px（印刷直角） | **14–18px（软角）** |
| 层次手段 | 1px 细线贯穿版面 | **留白 + 暖色柔影 + 光晕**，细线只用于功能件边界 |

### 1.3 概念三原则

1. **光只有一个来源。** 光源固定在左上 45°，所有光晕、高光、投影方向一致，强度只分三档（§2.3）。禁止局部自发光、禁止无来源的发光边框 —— 一旦光有两个来源，画面立刻变成廉价霓虹。
2. **金给温度，红给危险。** 琥珀金 = 交互与「正在发生」（播放中、主按钮、选中态、已播进度）；暗房红 = 危险与错误（删除、离线、失败），**永远不用于正向状态**。这是 v4「红只属于声音」的镜像规则，两套风格切换时语义不打架。
3. **版心大于装饰。** 秩序由「极大的留白 + 极大的字号级差」建立（刊头 44 vs 参数行 10）。装饰**只允许两种**：光晕、齿孔。其余全部交给留白 —— 任何第三个装饰母题都算违规。

### 1.4 情绪板（文字版）

- **Kodak Portra / Ektachrome** 的暖调人像与唱片内页：奶油高光、暖棕阴影、从不发灰
- **Kinfolk / Cereal** 的杂志版心：一张图占半页，其余全是白
- **Vogue / Harper's Bazaar** 的刊头：Didot / Bodoni 的极高粗细对比，字号敢到 56
- **暗房安全灯**（琥珀色）下的显影盘：黑屋子里唯一的光
- 35mm 胶片的**齿孔**与奶油色片基；镜头**光晕**溢出到高光边缘
- 唱片内页的**参数行**：`33⅓ · STEREO · 1978`

## 2. 设计语言

### 2.1 色彩：片基 / 墨 / 阳光 / 光晕

**日光（浅色）** —— 晒过太阳的奶油片基：

| 角色 | 日光 Daylight | 暗房 Darkroom | 用途 |
|---|---|---|---|
| 片基 `film.base` | `#F1E7D6` | `#16110C` | 窗口底、侧栏、滚动区画布 |
| 卡纸 `film.card` | `#FCF7EE` | `#211A13` | **唯一会浮起的表面**：卡片、下拉、Toast |
| 凹陷 `film.sunken` | `#E7DAC3` | `#110D09` | 进度轨槽、分段控件槽、输入框底 |
| 悬停 `film.hover` | `#F5EBDA` | `#2A2118` | 行 / 导航项 hover |
| 墨 `ink.text` | `#241C14` | `#F4EADA` | 正文、标题 |
| 墨 2 `ink.text2` | `#5C5044` | `#B3A288` | 次级文字 |
| 墨 3 `ink.text3` | `#74674F` | `#94876F` | 三级信息（参数行、计数） |
| 实心墨块 `ink.fill` | `#241C14` | `#F4EADA` | 选中块、反色刊头面板 |
| 阳光 `sun.base` | `#BE8420` | `#E2A748` | 强调色实底、进度已播、光晕源色 |
| 阳光深 `sun.deep` | `#96660F` | `#C08A2E` | 按压态、主按钮实底 |
| 阳光文字 `sun.ink` | `#8A5F0E` | `#F2C57E` | 金色**文字**（实底上不用这个） |
| 阳光底 `sun.tint` | `rgba(190,132,32,.10)` | `rgba(226,167,72,.14)` | 选中行底、标签底 |
| 胶片青 `cine.base` | `#3A6A62` | `#6EB2A6` | 同步中、信息提示（次级语义） |
| 暗房红 `darkroom.red` | `#A83A28` | `#E2705A` | **仅**危险 / 错误 / 离线 |
| 光晕 `glow` | `rgba(226,164,72,.19)` | `rgba(242,176,84,.15)` | 封面与卡片的暖色外溢 |
| 暖影 `shadow.warm` | `#4C3414` | `#4C3414` | 投影基色（**永远不是纯黑**） |
| 细线 `line.hairline` | `rgba(36,28,20,.14)` | `rgba(244,234,218,.14)` | 功能件边界 |
| 强线 `line.strong` | `rgba(36,28,20,.26)` | `rgba(244,234,218,.26)` | 输入框、图标栏分隔 |
| 刊头面板 | `#241C14` / 字 `#F1E7D6` | `#0F0B08` / 字 `#F4EADA` | **固定反色**：登录品牌区、正在播放刊头 |

**规则**

- **禁止纯黑与纯白**。阴影基色一律 `#4C3414`（暖棕），文字最亮是 `#FCF7EE`（卡纸白）。`#000` / `#FFF` 在任何令牌里都不允许出现。
- **光晕不是颜色，是光**：`glow` 只以 `box-shadow` / 径向渐变出现，**永不做文字色、永不做实底**。
- **固定反色刊头**：登录左栏与「正在播放」刊头在双主题下都是墨底纸字 —— 像杂志封面不随内页排版变色。这是 v5 唯一允许反色的区域。
- **金不用于危险，红不用于正向**，两色在同一屏内不并排出现（危险态出现时，金退到进度与播放键）。
- 封面统一走「**暖调双色**」处理（暖高光 + 暖棕阴影），冷色封面（青蓝调）需叠加 `rgba(226,164,72,.10)` 的暖色覆层，避免打破全屏色温。

### 2.2 字体：刊头衬线 + 界面无衬线 + 衬线数字

| 角色 | 字体栈 | 用途 |
|---|---|---|
| **刊头** display | `"Didot","Bodoni 72","Playfair Display","Times New Roman","Songti SC",serif` | 页面刊头、专辑名、艺人名、登录品牌字；**字重 400**（高对比衬线天生够粗，加粗会糊）、字距 `-0.01em` |
| **界面** UI | `-apple-system,"PingFang SC","Hiragino Sans GB",sans-serif` | 导航、按钮、表单、说明；字距 `+0.01em`、字重 400/500 |
| **数字** figure | `"New York",Georgia,"Iowan Old Style",serif` + `font-variant-numeric` | 时长、年份、曲目号、百分比、计数 |
| **标签** label | 同 UI，10–11px / 600 / 字距 `.14em` / 大写 | 参数行、分组标签、EXIF 风格元信息 |

- **中文刊头走宋体**（`Songti SC`）400 字重，**字号 ≥24 才允许使用** —— 宋体小字在 HiDPI 下发虚。
- **数字的两种形态**：**静态**数字（曲目号、年份、总时长）用 `oldstyle-nums`（旧体数字，有升部降部，与衬线正文同高，是杂志排版的标志）；**会跳动的**数字（播放计时）必须 `tabular-nums` 等宽。`"New York"` 同时提供 oldstyle 与 tabular 两套字形，可直接满足；若某环境回退到 Georgia（无 `tnum`），**计时回退到 `SF Mono`** —— 这条回退路径是硬要求，宁可破格也不许数字跳动。
- **参数行**是 v5 的签名细节：`10px / 600 / 字距 .18em / 大写 / tabular`，形如 `33⅓ RPM · STEREO · 1978`，贴在每张封面下方。它承担「这是实物唱片」的叙事，也是**唯一允许 10px 的位置**。

### 2.3 形状与光

**圆角（6 档，同心）**

| 令牌 | 值 | 用途 |
|---|---|---|
| `r-xs` | 4 | 徽标、进度滑块 |
| `r-sm` | 8 | 小按钮、分段控件内块 |
| `r-md` | 10 | 输入框、下拉项 |
| `r-lg` | 14 | 卡片、面板、Toast |
| `r-xl` | 18 | 大面板、正在播放主卡 |
| `r-cover` | 16 | 封面（**略小于卡片**，留出卡纸边） |
| `pill` | full | 所有按钮（主/次/胶囊标签） |

同心规则：内件圆角 = 外圆角 − 内边距（与 v3 同法；v4 因为直角而豁免，v5 必须遵守）。

**光（唯一的三档体系）** —— 全部用 `box-shadow` 实现，**零材质 API 依赖**，任何 macOS 版本表现一致：

| 档 | 日光 | 暗房 | 用途 |
|---|---|---|---|
| **L1 静置** | `0 1px 2px rgba(76,52,20,.10)` | `0 0 0 1px rgba(244,234,218,.06)` | 卡片、封面静置 |
| **L2 悬停** | `0 6px 18px -6px rgba(76,52,20,.22)` + `0 0 0 1px rgba(226,164,72,.19)` | `0 0 24px rgba(242,176,84,.12)` | hover、选中行、下拉项 |
| **L3 浮层** | `0 18px 44px -12px rgba(76,52,20,.32)` + `0 0 0 1px rgba(226,164,72,.22)` | `0 0 40px rgba(242,176,84,.18)` | Toast、设置窗口、正在播放主卡 |

- **暗房模式阴影不可见**（黑底上没有影子），所以暗房的层级**全部由光晕承担** —— 这是「暗房」与「夜场」的本质区别：v4 的夜晚是平的，v5 的夜晚在发光。
- **性能约束**：L2/L3 的 `box-shadow` 在滚动网格里代价可观。**静置网格只允许 L1**，L2 仅在 hover / 选中 / 播放中的**单个**元素上生效；正在播放页最多 3 个 L3 元素。
- **描边只用于功能件**（输入框、图标栏右缘、分隔线），**不用来划分区块** —— 区块划分交给留白与光（这是与 v4 最大的手法差异）。

### 2.4 视觉母题（四个，贯穿全页面）

| 母题 | 形态 | 出现位置 |
|---|---|---|
| **光晕 Halation** | 暖金半透明外溢，三档分级（L1/L2/L3） | 封面、主按钮、Toast、正在播放背景 |
| **齿孔帧 Sprocket** | 6 孔胶片齿孔条：1px 描边 + 3×4px 方孔，孔距 10px | 区块标题左侧、页头下沿、空态插画、侧栏品牌行 |
| **曝光刻度 EV Scale** | 3px 细轨 + 光圈圆点滑块 + 每分钟 1px 刻度点，已播为琥珀渐变 | **全局唯一进度形态**（含迷你条、队列、音频设置） |
| **刊头 + 参数行 Masthead & Spec Line** | 44px 高对比衬线大标题 + 斜体衬线导语 + 10px 全大写参数行 | 页面头部、专辑/艺人详情、正在播放、封面卡下方 |

### 2.5 动效：显影（Develop）

| 场景 | 规格 |
|---|---|
| 页面切换 | 240ms：`opacity 0→1` + `translateY 8px→0` + `saturate(.82)→1`（胶片显影感，`ease-out`） |
| 封面 hover | 200ms：L1 → L2，封面 `scale 1.00→1.02` |
| 播放中封面 | 12s 极缓 Ken Burns：`scale 1.00→1.03`（**减少动态效果时静止**） |
| 进度 / 滑块 | 160ms `ease-out`；轨高 3px → hover 5px |
| 播放中指示 | 金点呼吸，周期 **1600ms**（唯一允许的循环动效；减少动态效果时静止） |

**禁止**：弹簧回弹、位移 > 8px 的滑动转场、> 1 个循环动效、任何 `blur` 模糊动画。

## 3. 令牌表（与 `Theme.swift` 的对应命名）

> 落地时建议在 `Theme.swift` 中以 `FilmTokens` 独立枚举承载（对应现有的 `InkTokens`），与 `GlassTokens` / 纸墨令牌**并存**，由外观设置切换「视觉风格：玻璃 / 纸墨 / 胶片」。

### 3.1 颜色

```
film.base / film.card / film.sunken / film.hover      // 片基 / 卡纸 / 凹陷 / 悬停
ink.text / ink.text2 / ink.text3 / ink.fill           // 墨阶 + 实心墨块
sun.base / sun.deep / sun.ink / sun.tint              // 阳光金：实底 / 按压 / 文字档 / 8–14% 底
cine.base / cine.tint                                 // 胶片青（同步 / 信息）
darkroom.red / darkroom.tint                          // 暗房红（仅危险 / 错误 / 离线）
glow.halation                                         // 光晕源色（只进 box-shadow）
shadow.warm                                           // 暖影基色 #4C3414
line.hairline / line.strong
masthead.fill / masthead.ink                          // 固定反色刊头面板
```

### 3.2 字号

沿用现有 `Theme.TextStyle` 的 12 档阶梯（三套风格切换时版式不跳），**新增 3 档**：

| 新增令牌 | 字号 / 行高 | 字重 | 设计 | 用途 |
|---|---|---|---|---|
| `masthead` | 44 / 52 | regular | serif | 页面刊头、专辑名、正在播放大标题 |
| `figure` | 15 / 20 | regular | serif + oldstyle/tabular | 时长、年份、曲目号、计数 |
| `spec` | 10 / 14 | semibold | sans + 大写 + `.18em` 字距 | 参数行、元信息 |

其余档位沿用：`display 34 / title1 28 / title2 22 / title3 18 / title4 16 / bodyLG 15 / body 14 / bodySM 13 / footnote 12 / caption 11 / mono 12 / monoSM 11`。

**风格化解析**（现有机制已支持）：`TextStyle.design` 已按风格分支（`Theme.isPaper ? .serif : .default`），v5 增加一支 —— `display / title1 / title2 / title3 / masthead` 在胶片风格下解析为 `.serif`，**且 `display` 在 v5 下按 44 渲染**（其余风格仍是 34，保持 v3/v4 逐像素不变）。

### 3.3 间距 / 圆角 / 光

- **间距**：沿用 4pt 基线（2/4/6/8/12/16/20/24/32/40/48），**v5 新增两档大留白**：`breathe = 72`（区块之间）、`hero = 96`（页头与首屏之间）。这是「杂志版心」的物理基础 —— 不加这两档，v5 会退化成 v4 加圆角。
- **圆角**：§2.3 的 6 档 + pill。
- **光**：§2.3 的 L1/L2/L3 三档，`Elevation` 增加 `glow` 关联值（同一档同时产出阴影与光晕）。

## 4. 组件库

### 4.1 按钮

| 类型 | 规格 |
|---|---|
| **主按钮** | pill，高 44，水平内边距 24；**日光**：`sun.deep` `#96660F` 实底 + **卡纸白字**；**暗房**：`sun.base` 实底 + **深墨字 `#2A1E0B`**；L2 光晕 |
| **次按钮** | pill，高 44；卡纸底 + 1px `line.strong` + 墨字；hover 时 L1 → L2 |
| **文字按钮** | 墨字 + 12px 下划线（`text-underline-offset 3px`），hover 时下划线变 `sun.ink` |
| **图标按钮** | 三档 28 / 32 / 44；hover 卡纸底 + `r-sm`；键盘聚焦时同样显示（不依赖 hover） |
| **播放主键** | 直径 56 的实心圆（`ink.fill`）+ 纸白图标；播放中时圆环外侧加 L3 光晕 |

> **文字色为什么按主题分**：实测「浅色主题用 `sun.deep` 实底 + 纸白字」对比度 **4.68–8.73**，而「亮金实底 + 白字」只有 **3.0**（不达 AA）。深色主题反过来 —— 亮金实底 + 深墨字是 **5.70–7.65**，用白字只有 **1.9**。这条规则不许「统一成白字」。

### 4.2 表单控件

- **输入框**：高 44，`r-md`，卡纸底，1px `line.strong`；**聚焦** = 2px `sun.base` 环 + 外扩 4px `sun.tint`（不是系统蓝框）。

### 4.8 Toast / 空态 / 骨架

## 5. 窗口骨架与断点

骨架与快捷键契约**完全沿用** v3/v4（切风格不丢导航、不丢搜索词）：

五档断点（`LayoutSizeClass` W0–W4）沿用现有阈值（窗口宽 640 / 860 / 1100 / 1420），**只调整 v5 的密度值**：

| 档 | 窗口宽 | 侧栏 | 内容边距 | 网格 min | 网格间距 | 区块间 |
|---|---|---|---|---|---|---|
| W0 | < 640 | 图标栏 64 | **20** | **170** | **20** | **48** |
| W1 | 640–859 | 图标栏 64（可抽屉） | 24 | 180 | 20 | 56 |

### 8.1 对比度（实测值，WCAG 2.1）

**文字**

| 前景 | 背景 | 日光 | 暗房 | 结论 |
|---|---|---|---|---|
| `ink.text` | `film.base` | 13.70 | 15.74 | AAA |
| `ink.text` | `film.card` | 15.73 | 14.43 | AAA |
| `ink.text2` | `film.base` | 6.38 | 7.54 | AA |
| `ink.text2` | `film.card` | 7.33 | 6.91 | AA |
| `ink.text3` | `film.base` | **4.52** | **5.32** | AA（小字下限，已是终值） |
| `sun.ink` | `film.base` | **4.60** | 11.67 | AA |
| `sun.ink` | `film.card` | 5.28 | 10.69 | AA |
| `cine.base` | `film.base` | 5.02 | 7.67 | AA |
| `darkroom.red` | `film.base` | 5.19 | 5.98 | AA |

> `ink.text3` 的取值是被这条约束**反推**出来的：`#8E8068` 一类的「好看」灰在片基上只有 3.6–3.9，不达 AA；现在的 `#74674F` / `#94876F` 是满足 4.5 的最亮解，**不要再调亮**。

**按钮（实底 + 文字）**

| 主题 | 实底 | 文字 | 对比度 |
|---|---|---|---|
| 日光 · 阳光琥珀 | `#96660F` | `#FCF7EE` | 4.68 |
| 日光 · 落日橘 | `#9E4718` | `#FCF7EE` | 5.84 |
| 日光 · 胶片青 | `#245950` | `#FCF7EE` | 7.51 |
| 日光 · 暮紫 | `#543A78` | `#FCF7EE` | 8.73 |
| 暗房 · 阳光琥珀 | `#E2A748` | `#2A1E0B` | 7.65 |
| 暗房 · 落日橘 | `#EC8250` | `#2A1E0B` | 6.11 |
| 暗房 · 胶片青 | `#6EB2A6` | `#2A1E0B` | 6.66 |
| 暗房 · 暮紫 | `#A98BD6` | `#2A1E0B` | 5.70 |

**非文字（图形 / UI 边界，要求 ≥ 3:1）**：进度已播 vs 轨槽 = 日光 **3.62** / 暗房 **9.08**；焦点环 `sun.base` vs 片基 = 日光 **2.63** → **不达 3:1**，因此焦点环额外加 1px `ink.fill` 内描边（可达 13.7:1），聚焦永远不止靠金色。

### 8.2 规则

- **色彩永不作为唯一信号**：播放中 = 金条 **+** 光圈圆点 **+** 文字加粗；错误 = 红边 **+** 图标 **+** 文案；选中 = 卡纸浮起 **+** 金条 **+** 图标填充。
- **焦点可见**：所有可聚焦元素有 2px 金环 + 1px 墨内描边；`Tab` 顺序 = 视觉顺序。
- **图标按钮全部有 `accessibilityLabel`**（沿用现有基线，不因换风格回退）。
- **hover 态必须有键盘等价物**：hover 才出现的操作（行内「更多」）在键盘聚焦时同样显示。
- **动态排版**：字号走 `.textStyle(_:)` / `@ScaledMetric`，随系统文本大小缩放；刊头在放大 2 档后允许降到 `display`。
- **减少动态效果**：Ken Burns、呼吸、shimmer 全部静止；转场 240ms → 120ms 线性。
- **键盘**：沿用 ⌘F / 空格 / ⌘←→ / ⌘[ / ⌘1–5 / ⌘, / Esc 契约，切风格不失效。
- **描边可见性**：白发（`rgba(255,255,255,.18)`）的封面内描边在亮封面上不可见 —— 封面内描边必须同时有 1px 外圈 `line.hairline` 兜底。

### 9.2 强调色色阶（`AccentRamp.forChoice` 新增分支）

```swift
case .sun:  // v5 签名色：阳光琥珀
    return .fixed(
        base: 0xBE8420, light: 0xDCA94E, dark: 0x96660F, text: 0x8A5F0E,
        darkBase: 0xE2A748, darkLight: 0xF2C57E, darkDark: 0xC08A2E
    )
```

预览里另给的三个可选强调色（落日橘 / 胶片青 / 暮紫）色阶见预览 HTML 的 `data-accent` 变量组，落地时可只加 `.sun` 一个 case，其余复用现有四色。

### 9.3 与 v4 的相似度风险

v4 与 v5 都以「暖」为主，**必须靠 §1.2 的四条硬性差异隔开**。落地时的自检：把两套风格的同一页面截图并排 —— 若第一眼分不出，优先加大**字号级差**（v5 的刊头必须到 44）与**留白**（区块间 72/96），而不是继续调色。色差是最弱的区分手段。

### 9.4 性能注意

- 光晕 `box-shadow` 只在 hover / 选中 / 播放中生效，**静置网格只允许 L1**；W0 窄窗下网格元素少，可放宽。
- 暗房的 L2/L3 是**大面积低透明度光晕**（`0 0 40px`），在 1000 行列表里会显著掉帧 —— 列表行**永远不用 L2 光晕**，改用卡纸底色切换。
- 显影 shimmer 用 `transform` + `opacity`（GPU 合成），**不要动 `background-position`**。

## 10. 验收清单

- [ ] 刊头达到 44px 高对比衬线，参数行 10px；同屏字号级差 ≥ 4×（§2.2）
- [ ] 全屏只有一处大光源（登录右栏 / 正在播放背景的径向光），方向一致（§1.3 原则 1）
- [ ] 金色只出现在：播放中、主按钮、选中态、已播进度（§1.3 原则 2）
- [ ] 红色只出现在：危险 / 错误 / 离线，**没有任何正向状态用红**
- [ ] 静置网格无 L2/L3 光晕；滚动 1000 行列表掉帧 < 5%（§9.4）
- [ ] 卡片、封面、输入框圆角符合 §2.3 同心规则（内 = 外 − 内边距）
- [ ] 区块之间无贯穿细线，只用 72/96 留白分隔（§1.2 硬性差异）
- [ ] 曲目行高 52、专辑行 64；hover 抬为卡纸而非变色（§4.4）
- [ ] 进度条全应用同构（`EVProgress`），无第二套进度形态（§4.5）
- [ ] 封面下方参数行存在，且 `33⅓ RPM · STEREO · 年份` 三要素齐全（§4.6）
- [ ] 计时数字等宽不跳动（`tabular-nums`，或回退 `SF Mono`）；静态数字为 oldstyle（§2.2）
- [ ] §8.1 对比度表逐项达标；`ink.text3` 未被调亮
- [ ] 减少动态效果下：Ken Burns / 呼吸 / shimmer 全部静止，转场 120ms（§7）
- [ ] 切风格不丢导航栈、搜索词、侧栏宽度（沿用现有契约）
- [ ] 键盘全路径可达：Tab 顺序 = 视觉顺序，hover 操作有键盘等价物（§8.2）
- [ ] v3 玻璃与 v4 纸墨的渲染**逐像素不变**（回归验证）
