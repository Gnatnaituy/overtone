# Overtone UI 重新设计规范 v2

> 适用：Overtone（泛音）—— 原生 macOS Jellyfin 音乐客户端（SwiftUI）
> 范围：视觉语言重做 + 信息架构重排 + 组件库 + 交互/导航规范 + 可访问性基线
> 平台边界：**仅 macOS 窗口**，响应式目标为「窄窗口不破版」，不引入 iOS / iPadOS 布局

---

## 1. 设计目标与目标用户

### 1.1 现状诊断

通读 `Sources/JellyfinMac` 后，当前实现的六个结构性问题（这是本次重设计的出发点）：

| # | 问题 | 现状 | 影响 |
|---|---|---|---|
| P1 | **没有首页** | 登录后直接落到「资料库/歌曲」列表，README 里的「首页/继续观看」已被音乐模块取代 | 启动后要自己找入口，冷启动到出声路径过长 |
| P2 | **没有设置页** | 无服务器管理、音质、缓存、外观、快捷键说明；退出登录只是侧栏底部一个 28pt 图标 | 弱网/外网穿透用户无法调音质；账号管理藏得太深 |
| P3 | **侧栏职责混杂** | 「搜索」被当作一级页面；「收藏/最近播放/最常播放」与一级导航同级；全部播放列表平铺在侧栏 | 列表条目无限增长会挤爆侧栏；导航层级认知成本高 |
| P4 | **令牌不收敛** | 圆角混用 4/5/6/8/10/12/16；阴影 0.06/0.10 与 `glow` 三种并存；选中态「主色实底白字」与 hover「浅灰底」是两套语言 | 视觉统一性不足，新增页面时必然走样 |
| P5 | **窄窗口策略粗暴** | 仅 `LayoutSizeClass` 两档（<860 收起侧栏），收起后导航完全消失，只剩一个展开按钮 | 半屏常驻（本产品典型用法）时导航丢失 |
| P6 | **可访问性欠账** | hover 才出现的「收藏/更多」键盘不可达；进度条是 `DragGesture` 自绘，无法键盘调节；`tertiaryText #9CA3AF` 白底对比度约 2.6:1；字号全部硬编码，不支持动态字号 | VoiceOver / 键盘用户、弱视用户被挡在门外 |

### 1.2 设计目标

| 目标 | 表述 | 可度量标准 |
|---|---|---|
| **G1 一屏找到想听的** | 以首页为枢纽，把「继续播放 / 最近添加 / 最常听」前置 | 冷启动 → 开始播放 ≤ 2 次点击（现状 ≥ 3 次） |
| **G2 一套令牌，全页一致** | 圆角收敛到 6 档、阴影 3 档、选中态 1 套语义 | 新页面 0 处硬编码色值/圆角，全部走 `Theme` 令牌 |
| **G3 窄窗不破版、不丢导航** | 5 档断点；侧栏在窄窗口降级为 **图标栏 64pt** 而非消失 | 窗口拉到 520pt 宽仍可完成「选库 → 选专辑 → 播放」全流程 |

### 1.3 目标用户

**主用户：自建媒体库的音乐收听者**
- 25–45 岁，macOS 13+，家里跑 NAS / Jellyfin，曲库 1k–50k 首
- 典型场景：窗口常开在半屏（约 700–900pt 宽），边工作边听；偶尔全屏浏览封面墙
- 诉求：**快**（找得到、点得准）、**静**（不要弹窗和花哨动效）、**稳**（进度多端同步）
- 设计含义：一级导航永远可见（→ G3）；默认不打扰的动效（→ 尊重 Reduce Motion）；播放控件常驻（迷你播放条永不消失）

**次用户：家庭共享成员**
- 同一台服务器的多个账号，偶尔切换；媒体库结构由别人维护
- 设计含义：设置页必须有「服务器与账号」分组，切换账号不清本地播放列表

**约束型用户（需被照顾）**
- 外网穿透 / 弱网：需要「音质与直连策略」「缓存上限」→ 设置页
- VoiceOver / 键盘用户：所有功能不能只靠 hover（→ §8）
- 弱视 / 大字号：支持系统文本大小，正文对比度 ≥ 4.5:1

### 1.4 非目标

- 不做 iOS / iPadOS 布局（本次明确排除）
- 不做深色主题的完整落地（令牌层预留 `colorScheme` 分支，视觉稿只交付浅色）
- 不重做视频播放模块（本规范只覆盖音乐链路）
- 不改动数据层、播放引擎与 API 调用

## 2. 信息架构与导航

### 2.1 新旧 IA 对照

```
【现状】侧栏（一级导航）
  资料库 / 播放列表 / 正在播放 / 搜索 / 收藏 / 最近播放 / 最常播放 / <全部播放列表平铺>

【v2】侧栏（一级导航，固定 5 项 + 1 个可折叠分组）
  ♪ 首页              ← 新增（P1）
  ▦ 资料库            （专辑 / 艺人 / 歌曲 / 播放列表 四分段）
  ≡ 播放列表          （全部列表页；侧栏内「我创建的」分组折叠，默认 6 项 + 显示全部）
  ◉ 正在播放
  ⌕ 搜索              （常驻搜索框上移到内容区顶栏，一级入口保留）
  ─────────────
  播放列表（折叠，>6 项显示"显示全部"）

  首页承载的模块（从侧栏下沉）：继续播放 · 快速入口（收藏/最近播放/最常播放/随机）· 最近添加 · 最常播放
  设置入口：侧栏底部账号菜单 →「设置…」（⌘,）
```

变化要点：
1. **搜索上移**：搜索框常驻内容区顶栏（⌘F 聚焦），结果仍可作为一级页呈现历史/热门。
2. **收藏 / 最近播放 / 最常播放** 从一级导航下沉为首页模块 + 快速入口，减少侧栏噪声（P3）。
3. **播放列表分组默认折叠**，避免无限增长（P3）。
4. **新增首页**（P1）与**设置页**（P2）。

### 2.2 导航模型

- 一级切换：替换栈（`stack = [page]`），无返回按钮，侧栏高亮指示当前位置。
- 二级推进：`push(page)`，详情页顶部显示**面包屑返回栏**（`← 资料库 · 专辑名`），不是孤立的「返回」按钮。
- 深链保护：从搜索进入专辑 → 返回时回到搜索结果而非首页（栈保持 push 语义）。
- 快捷键：

| 快捷键 | 行为 |
|---|---|
| `⌘F` | 聚焦搜索框（任何场景） |
| `空格` | 播放 / 暂停（输入框聚焦时放行给输入框） |
| `⌘→ / ⌘←` | 下一曲 / 上一曲 |
| `⌘[` | 返回上一级 |
| `⌘1…⌘5` | 切换一级页（首页/资料库/播放列表/正在播放/搜索） |
| `⌘,` | 打开设置 |
| `⌫` | 删除选中的播放列表项 |

### 2.3 页面清单

| 页面 | 状态 | 说明 |
|---|---|---|
| 登录页 | 重做 | 左右分栏，窄窗降级单列 |
| **首页** | **新增** | 继续播放 + 快速入口 + 最近添加 + 最常播放 |
| 列表页（资料库 / 播放列表 / 收藏 / 最近播放 / 最常播放） | 重做 | 统一顶栏 + 分段 + 视图切换 + 空态 |
| 详情页（专辑 / 艺人 / 播放列表） | 重做 | 统一头部骨架 + 面包屑 |
| **设置页** | **新增** | 6 个分组 |
| 正在播放页 | 重做 | 窄窗待播清单改抽屉 |

## 3. 设计令牌（Design Tokens）

### 3.1 颜色

**表面（Surfaces）**

| 令牌 | 值 | 用途 |
|---|---|---|
| `canvas` | `#F5F6F8` | 窗口内容区底色，让白色卡片浮起 |
| `surface` | `#FFFFFF` | 卡片、面板、设置分组 |
| `surfaceSunken` | `#F2F3F6` | 表头、次级控件底、分段控件容器 |
| `surfaceHover` | `#EEF0F4` | 行悬停 |
| `surfaceSelected` | `rgba(76,83,216,0.08)` ≈ `#EEF0FF` | 选中行底色 |
| `borderSubtle` | `#E9EBEF` | 卡片描边、分隔线 |
| `borderDefault` | `#DDE0E6` | 输入框、次级按钮描边 |
| `borderStrong` | `#C6CBD4` | 拖拽热区、强分隔 |

**文字（Text）** — 对比度基于 `#FFFFFF` 底

| 令牌 | 值 | 对比度 | 用途 |
|---|---|---|---|
| `textPrimary` | `#14171C` | 16.7:1 | 标题、正文 |
| `textSecondary` | `#5B6472` | 5.96:1 | 副标题、元信息 ✅ AA |
| `textTertiary` | `#7C8698` | 3.67:1 | 分组标题、占位符、图标（**禁止用于正文**） |
| `textOnAccent` | `#FFFFFF` | — | 主色底上的文字 |

**品牌（Brand）** — 「靛蓝主音 + 泛音青」双色体系

| 令牌 | 值 | 说明 |
|---|---|---|
| `brand400` | `#6B71E3` | 渐变起点 |
| `brand500` | `#4C53D8` | **主色实底**（白字 5.86:1 ✅ AA） |
| `brand600` | `#3E45C0` | 按压 / 激活 |
| `brandGradient` | `135deg, #6B71E3 → #3E45C0` | 主按钮、Logo、激活分段 |
| `brandTint` | `rgba(76,83,216,0.08)` | 选中底、焦点光晕 |
| `overtoneTeal` | `#12B8A6` | 第二谐波：频谱柱、正在播放律动（装饰用） |
| `tealText` | `#0B7C6A` | 青色文字态（5.11:1 ✅ AA） |

> 为什么换掉 `#2563EB`：`#2563EB` 是通用 UI 蓝，缺少辨识度。新主色偏靛紫，与产品名「泛音」的谐波意象呼应，也与登录页已有的蓝+青极光底（`#5BC8C8`）同源；实测白字对比度 5.86:1，安全。

**语义（Semantic）**

| 令牌 | 值 | 对比度（白底） |
|---|---|---|
| `success` | `#14855F` | 4.61:1 ✅ |
| `warning` | `#A75B09` | 5.00:1 ✅ |
| `danger` | `#C8372D` | 5.17:1 ✅ |
| `favorite` | `#E04B78` | 3.85:1 ✅（图标/大字号达标） |

### 3.2 字体

- 主字体：`SF Pro Text / -apple-system`（系统字体，跟随 macOS）
- 数字/时间码：`SF Mono`，避免进度时间跳动时宽度抖动
- 字重：400 Regular / 500 Medium / 600 Semibold / 700 Bold（**不使用 Ultralight / Black**）

| 层级 | 字号 / 行高 | 字重 | 用途 |
|---|---|---|---|
| `display` | 34 / 40 | 700 | 登录页主标题、空态 |
| `title1` | 28 / 34 | 700 | 详情页专辑名 |
| `title2` | 22 / 28 | 700 | 页面大标题、正在播放曲名 |
| `title3` | 18 / 26 | 600 | 区块标题 |
| `title4` | 16 / 24 | 600 | 卡片标题、分组标题 |
| `bodyLG` | 15 / 22 | 400 | 长正文 |
| `body` | 14 / 20 | 400 | 默认正文 |
| `bodySM` | 13 / 18 | 400 | 列表副标题、菜单 |
| `footnote` | 12 / 16 | 400 | 元信息、时间码 |
| `caption` | 11 / 16 | 500–600 | 分组标题（大写 + tracking 0.06em） |

规则：**最小 11pt**；所有字号改为相对动态字号（`font(.body)` + `dynamicTypeSize`），上限 `xxxLarge` 时布局允许换行不允许裁切。

### 3.3 间距 / 圆角 / 阴影

- 间距基线 **4pt**：`2 · 4 · 6 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48`
  - 卡片内边距 16；区块间距 32；页面水平边距随断点 16/20/24/28/32
- 圆角（**收敛为 6 档**，现状 7 种 → 6 种且不再出现 5 / 10）：
  `xs 4` · `sm 6` · `md 10` · `lg 14` · `xl 20` · `full 999`
  - 小控件（chip/图标按钮）6 · 输入框/按钮 10 · 卡片 14 · 封面 10（专辑）/ 20（正在播放大封面）/ 圆形（艺人）
- 阴影（**收敛为 3 档**）：
  - `e1` `0 1px 2px rgba(16,20,28,.06)` — 卡片静态
  - `e2` `0 2px 8px rgba(16,20,28,.08), 0 1px 2px rgba(16,20,28,.06)` — hover / 下拉 / 面板
  - `e3` `0 12px 28px rgba(16,20,28,.12), 0 2px 6px rgba(16,20,28,.06)` — 正在播放大封面、设置窗口
  - 焦点环：`1px solid brand500 + 0 0 0 3px rgba(76,83,216,.28)`（**替代** 系统蓝框，键盘可见）

### 3.4 动效

| 令牌 | 曲线 / 时长 | 用途 |
|---|---|---|
| `motionMicro` | 120ms `cubic-bezier(.2,0,.2,1)` | 按压、hover 换底 |
| `motionBase` | 200ms 同上 | 下拉、面板、Toast |
| `motionPage` | 260ms | 页面切换（位移 8pt + 淡入） |
| `motionSpring` | spring(response 0.35, damping 0.85) | 迷你播放条、卡片入场 |
| 错落 | 30ms × index，最多 10 项 | 网格/列表入场 |

- **Reduce Motion**：系统开启后，所有位移/缩放动画降为 0，仅保留 120ms 透明度过渡。
- 正在播放的频谱柱（EqualizerBars）在 Reduce Motion 下静止为三根等高柱。

### 4.5 设置页（新增）

| 分组 | 项目 |

| 通用 | 启动时自动连接、默认打开页面、关闭窗口时继续播放、语言 |

| 外观 | 主题（浅色/深色/跟随系统）、强调色（靛蓝/青/紫）、降低动效、显示歌词 |
| 媒体库 | 上次刷新时间 + 「立即刷新」、图片缓存上限（步进器 GB）、清除缓存 |
| 服务器与账号 | 服务器地址（只读 + 修改需重新登录）、当前用户、切换用户、退出登录（危险按钮） |
| 关于 | 版本、开源许可、非官方声明、**快捷键速查表** |

- 行样式：左标签 13（secondary 说明 11 在下方）+ 右控件；行高 44；组间距 24；每组一张白卡（`radius-lg` + `borderSubtle`）
- 控件尺寸：开关 36×20、下拉 32 高、滑杆轨道 4pt（把手 16）、步进器 32 高、文本输入 240×32
- 危险操作：`danger` 描边按钮 + 二次确认弹窗

### 4.6 正在播放页 + 迷你播放条

**宽窗口（内容区 ≥1024）**
- 左主区（flex）：封面 `min(400, 可用高度-信息区)`，圆角 20 + `e3` → 曲名 22/700（艺术家 · 专辑 13）→ 进度区 480 宽（原生 Slider + 两侧等宽时间码 11）→ 控制区 5 键（随机 40 / 上一首 40 / 播放 56 主色圆 / 下一首 40 / 循环 40，间距 24）
- 右栏 320「待播清单」：标题 13/600 + 行 56（封面 40 + 标题 + 时长），可拖拽排序
- 歌词：切换后在主区下方展开，行高 28，当前行 16/600 主色，非当前 14 tertiary

**窄窗口（<1024）**
- 单列：封面自适应 140–260；待播清单降级为底部**可展开抽屉**（按钮「待播 N 首 ▾」，展开高度 `min(40% 视高, 320)`，不再压缩封面到 180pt 以内）

**迷你播放条**（高 68，W0 时 56）
- 左 220：封面 48（圆角 6）+ 曲名 13 + 副标 11（点击 → 正在播放页）
- 中 max 560：控制 5 键（26–36pt）+ 进度条（4pt 轨道，hover 6pt + 把手 10）
- 右 220：静音（26）+ 音量滑杆 96 + 队列（26）+ 展开（26）
- W0/W1：隐藏时间标签与音量区，左区自适应，中区优先
- 播放状态除颜色外必须有**图标区分**（频谱柱动效），不靠颜色单一通道（色觉障碍）

**统一规则**
1. **hover 不能是唯一入口**：任何 hover 才出现的控件（收藏、更多、拖拽把手），在键盘 `focus` 时必须同样出现，并可通过 `Tab` 到达。
2. 所有可点击元素有 `contentShape`，热区 ≥ 28pt（图标按钮建议 32）。
3. 颜色不单独承载语义：播放中用频谱图标、错误用图标+文字、成功用图标+文字。

## 7. 交互与动效

| 场景 | 反馈 |
|---|---|
| 点击播放 | 迷你播放条从底部上移 12pt + 淡入（260ms）；曲目行变选中态；封面角标变暂停 |
| 加入队列 / 收藏 | Toast（底部居中，3s）；心形填充 + `spring(0.3, 0.6)` |
| 页面切换 | 260ms，位移 8pt + 淡入；列表错落 30ms×index（≤10 项） |
| 拖拽进度 | 拖动时移除进度条动画；松手后 200ms 恢复线性动画 |
| 窗口拉窄 | 侧栏 → 图标栏用 200ms 宽度动画，不做布局跳变 |
| 加载 | 骨架屏；>3s 才显示 spinner |
| 错误 | 内联红色提示 + 重试按钮；网络类错误带「检查服务器地址」跳转设置页 |
| 右键菜单 | 曲目行：下一首播放 / 添加到队列 / 添加到播放列表 / 收藏 |

**Reduce Motion**：位移与缩放动画全部置 0，仅保留 120ms 透明度；频谱柱静止。

## 8. 可访问性基线（WCAG 2.1 AA）

| 项 | 要求 | 落地动作 |
|---|---|---|
| 对比度 | 正文 ≥ 4.5:1，大字（≥18pt）与图标 ≥ 3:1 | 废弃 `tertiaryText #9CA3AF`（2.6:1）作正文；新 `textTertiary #7C8698` 仅用于非正文 |
| 焦点可见 | 所有可聚焦元素有 3pt 主色光晕焦点环 | 统一 `.focusRing()` 修饰符，替代系统默认 |
| 热区 | 图标按钮 ≥ 28pt（建议 32），行 ≥ 44 | 现 26pt 的播放控制键统一到 28–32 |
| 键盘可达 | hover 控件必须在 focus 时出现并可 Tab 到达 | 用 `@FocusState` 驱动收藏/更多按钮的可见性，**不只靠 `@State hovered`** |
| VoiceOver | 图标按钮全部有 label；曲目行合并为单元素 | `accessibilityElement(children: combine)`：「第 3 首，曲名，艺人，3:42」；播放按钮带 `accessibilityValue`（播放中/已暂停） |
| 动态字号 | 支持系统文本大小（11pt 起，xxLarge 不裁切只换行） | 字号改为 `Font.body` / 相对缩放，移除硬编码 `size:` |
| 进度调节 | 进度条可键盘微调 | 改用原生 `Slider` 或自绘 + `.accessibilityAdjustableAction`（±5s） |
| 色觉 | 状态不靠颜色单通道 | 播放中加频谱柱图标；错误加图标；收藏加填充/描边差异 |
| 动效 | 尊重「减少动态效果」 | 全局 `@Environment(\.accessibilityReduceMotion)` 分支 |
| 语义结构 | 分组标题、区块用 `accessibilityAddTraits(.isHeader)` | 首页区块与设置分组 |
