可交互：侧栏切换页面 · 主题 / 强调色即时切换（设置 → 外观）· 宽窄窗切换（窄窗 = W1 图标栏 + 抽屉，点汉堡按钮）· 播放条与正在播放进度可拖拽 · 收藏 / Toast / 二次确认弹窗（设置 → 清除缓存 / 退出登录）· 菜单与下拉 · 正在播放「封面 / 歌词」切换 · 快捷键 ⌘F 空格 ⌘1–5 Esc。
Liquid Glass：chrome 层（侧栏 / 顶栏 / 播放条 / 菜单 / 弹窗 / Toast）为玻璃材质并悬浮化，统一圆角 10（窗口 / 三块玻璃面板 / 全部封面一致），内容层保持不透明实底；「降低动效」开关同时演示「降低透明度」无障碍回退（玻璃 → 实底 + 描边）。材质令牌见 UI-Redesign-v3.md §7。
规格对应：侧栏 240 / 图标栏 64 · 顶栏 64 · 播放条 68（宽窄一致）· 圆角统一 10（窗口/面板/封面）· 阴影 e1–e3（深色以描边替代）· 断点 W0–W4 · 对比度 WCAG AA 实测通过。
