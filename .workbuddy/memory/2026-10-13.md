## UI v4「纸带与信号 Tape & Signal」—— Editorial 印刷风 B 方案（用户：再设计一套 UI）
- 动机：v2/v3 均为玻璃/数字方向，用户要「另一套」。v4 走完全相反的视觉语言：1970s 音乐印刷品 + 模拟台机美学，定位为与 v3 并行的「签名皮肤」，**不覆盖 v3**，信息架构/五档断点/令牌阶梯全部继承。

## v4「纸带与信号」落地实现（用户：实现主题切换 + 添加这套主题）
- 形态：**双轨视觉风格**而非覆盖 —— `Theme.swift` 新增 `enum VisualStyle { glass, paper }` + `Theme.Paper` 全套纸墨令牌；`GlassTokens`/`InkTokens` 两套令牌同时构造、切换只换引用（令牌实例稳定是硬约束，见 `AccentTokens` 注释）。默认仍是玻璃，设置 → 外观 → 视觉风格切换，**即时生效**（`.id(appVisualStyle)` 重建呈现层）+ 重启保持。
- 分工（Agent Teams，4 写手 + 1 验收，按文件写域切分，零冲突）：theme-core（Theme/AppSettings/JellyfinApp/SettingsView）、paper-ui（新建 `Components/PaperComponents.swift` + Components.swift）、tracks-player（MediaComponents/MiniPlayerBar/NowPlaying/Queue/TrackInfo/MusicPlayerModel）、pages（MainView/HomeView/LoginView/Music 各页）。共享接口先冻结在 `/tmp/overtone-v4-contract.md` 再并行开工。
- 关键裁决：① 点线策略 —— 详情表/队列/Top10/搜索用点线行（56/48），资料库列表视图用定宽对齐列不用点线（`MusicRow(rowStyle:)` 一个参数切换）；② `.id` 只挂在「持有呈现层但不持有页面状态」的层（MainView 的 HStack、SettingsView 内容、RootView 的登录分支），这样导航栈/搜索词/侧栏宽度存活；③ 切风格时强调色跟随签名色（靛蓝 ↔ 信号红），泛音青/紫不覆盖。
- **P0 拍到的坑（值得记）**：SwiftUI 的窗口恢复标识由**场景泛型类型签名**派生（`NSWindow Frame SwiftUI.WindowGroup<…RootView…>`）。本次给场景加了 `.environment(\.appVisualStyle,…)`，签名一变，macOS 拿旧标识恢复 → SwiftUI 返回 `window=0x0` → **启动后一个窗口都没有**（日志 `has no restoredWindow, skipping ordering`）。修法：`JellyfinApp.init()` 里 `AppDelegate.disableWindowStateRestoration()` 写 `ApplePersistenceIgnoreState=true` 关掉 talagent 恢复；窗口尺寸仍由 `NSWindow Frame` 偏好保持。**任何 SwiftUI 应用改视图结构后升级都可能踩这个，值得引以为戒。**
- **验收工具链踩的坑**：`CFFIXED_USER_HOME` **不能**隔离 macOS 偏好 —— cfprefsd 是按用户共享的守护进程，`defaults write com.jellyfin.mac-client` 直接写到使用者的真实偏好（一度把使用者偏好文件写坏，已用备份副本还原：token/serverURL/username/settings.* 均完好）。正确做法：**用启动参数域**（`-settings.visualStyle paper`）临时覆盖，不落盘。已写进 `docs/build-notes.md`。
- 新增开发脚本：`scripts/dev-typecheck.sh`（目录锁串行化 `swift build`，多人协作防增量互相踩）、`scripts/dev-shot.sh`（按窗口 id 截图做 UI A/B；`--style/--theme` 走启动参数；`--size` 因 SwiftUI 会回弹不可靠）。注意 `settings.visualStyle` 存的是 rawValue（`glass`/`paper`），传「纸墨」会静默回落玻璃。
- 验证结论：玻璃模式与改动前同尺寸截图**逐像素一致**（平均绝对差 0.0）；纸墨浅/深截图目检通过（规则标签、点线行、墨块主按钮、方形开关、衬线标题、选中墨块+左缘红条）；设置里 press「纸墨」主窗口当场改观且不弹回首页、强调色自动跟随信号红。
- 验收（独立 teammate，未改产品代码）结论：P0 = 0；玻璃零回归逐像素一致；纸墨形态取样与令牌值吻合；切换即时且不弹回页面。**报出 1 个 P1 + 3 个 P2**，Lead 处理：
