# 2026-10-28

## 飞牛云 NAS（fnOS 音乐）接入工作量调研

- 结论：三条路径可选。A) 「音桥」fn-music-bridge（fnOS FPK 应用，模拟 Jellyfin/Subsonic 协议，Overtone 零代码直连 http://NAS_IP:14040）；B) 原生 API 直连（推荐长期方案，估 8-12 个工作日）；C) fnOS 装 Jellyfin（零代码但与飞牛音乐曲库不互通）。
- 飞牛音乐原生 API：`/music/api/v1/*`，无官方文档。参照实现：Liusound 的 fnOS 适配器、Raduap/FN-Music-Apple（Electron）、qianlipp/fn-music-bridge。
- 认证：请求需 `authx` 签名头 = `md5(PREFIX_pathname_nonce_ts_payload_KEY)`（PREFIX=`NDzZTVxnRKP8Z0jXg1VAMonaG8akvh`，KEY=`6D5602D4-A342-4799-A0F0-BB795E7167D0`；GET 签名排序后 query 串的 md5，其余签 body 的 md5）。token 经 `Cookie: music-token=` 传递。登录两路：`/api/v1/user/password-login`（password 先 SHA-256）与 NAS OAuth（fnOS 登录页拿 code → `/api/v1/user/auth-login` 换 userToken）。code 99999 = token 失效需重登。
- 主要 endpoint：album/list、album/detail、track/list、track/album-detail/list、track/artist-detail/list、artist/list、genre/list、favorite-track/list+create+delete、playlist/list+create+update+delete+add-track+remove-track、search/track|album|artist、lyric/list（LRC 原文）、static/cover?coverId=&size=、track/stream?guid=。
- Overtone 改造面：`APIClient.shared` 54 处引用（14 文件）、`BaseItemDto` ~110 处（23 文件）、总计 15850 行 Swift。UI 层可保留，核心工作是引入 MusicService 协议抽象 + fnOS 模型映射。
- 风险：API 无文档无稳定性承诺（fnOS 更新可能破坏）；macOS 端 OAuth 回调建议 WKWebView 内嵌登录页截获 code（ASWebAuthenticationSession 自定义 scheme 是否被 fnOS 支持待验证）。
