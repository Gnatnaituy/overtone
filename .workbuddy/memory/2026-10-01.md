## UI 重新设计（v2 设计规范，未动 Swift 代码）
- 用户确认范围：仅做 macOS 窄窗口自适应（不做 iOS 布局）；交付 = 设计规范 + HTML 高保真预览。
- 通读了 Theme.swift / MainView.swift / Components.swift / MiniPlayerBar / LoginView / MusicLibraryView / MusicAlbumView / NowPlayingView，诊断出 6 个结构问题：无首页、无设置页、侧栏职责混杂、令牌不收敛（7 种圆角/3 套阴影）、窄窗口仅 2 档且侧栏完全消失、可访问性欠账（hover-only 控件、tertiary 2.6:1、硬编码字号）。
- 设计决策：主色由 #2563EB 换为靛蓝 #4C53D8（白字 5.86:1）+ 泛音青 #12B8A6 第二强调色；圆角收敛 6 档、阴影 3 档；断点由 2 档扩为 5 档（W0<640 … W4≥1340），窄窗侧栏降级 64pt 图标栏而非消失；新增 HomeView / SettingsView 规划。
- 产物：`docs/ui-design/UI-Design-Spec.md`（完整规范）、`docs/ui-design/preview.html`（hash 路由：#p1…#p6，#p4-s1…s6 子页）。
- preview.html 调试经验：Chrome headless 截图验证（`--headless=new --screenshot --virtual-time-budget` + file://hash）；两个坑——① 网格子项需 `min-width:0`，否则 1fr 列被 1000px 稿框的 min-content 撑爆导致 JS 缩放失效；② 顶层 Tab 与页面稿子 Tab 共用 `.tab` 类时，事件处理器与 `.on` 清除都必须限定 `.tabs .tab`，否则点顶层 Tab 会误清子 Tab 高亮并因 getElementById(undefined) 抛错清空内容区。

## 按 v2 规范重写应用 UI（Swift 落地）
- 令牌层 Theme.swift 全量重写：canvas/surface/surfaceSunken/borderSubtle/brandTint/overtoneTeal 等新令牌，圆角 6 档、阴影 3 档、动效 4 档；`LayoutSizeClass` 由 2 档扩为 W0–W4（含侧栏形态/边距/网格/详情页/播放条降级）。字号走 `.textStyle(_:)` + `@ScaledMetric` 支持动态字号。
- 新增 HomeView（继续播放/快速入口/最近添加/最常播放）、SettingsView（6 分组）、AppSettings（设置数据源 + `\.appReduceMotion` 环境值）；Components 拆成 Components.swift（通用）+ MediaComponents.swift（封面卡片/曲目表/顶栏/面包屑）。
- 踩坑记录（都是像素级排查出来的）：
  - `SidebarDivider` 作为 HStack 布局项占 12pt，自身透明露出 canvas 底色 → 白色侧栏与白色顶栏之间出现窗口全高的灰色竖带。改为 overlay + `offset(x: sidebarWidth - 6)`，不占布局宽度。
  - `.menuStyle(.borderlessButton)` 会**吞掉 label 内的背景与描边**：头像渐变圆、排序控件白底描边全部消失。新增 `TokenMenu`（外观层正常绘制 + 透明 Menu 覆盖负责弹出/命中）。
  - `Window` 场景 + `openWindow(id:)` 在窗口已存在但被 orderOut 后不会重新显示（`onscreen=false`，⌘, 打不开设置）。改用 `Settings` 场景（系统菜单自带 ⌘,），侧栏入口走 `NSApp.sendAction(showSettingsWindow:)`。
  - `WindowManager.apply` 原本 `isHidden = true` 隐藏红黄绿三键，且对**任何**成为 key 的窗口生效（会误改设置窗口标题栏）→ 改为保留三键 + 只作用于 `WindowManager.mainWindow`。
- **外观取决于 `LC_BUILD_VERSION.sdk`**：macOS 用该字段判断 App 是否按当前设计语言（Liquid Glass）绘制。SwiftPM 会把它写成 `platforms:` 声明的部署目标（13.0），于是红黄绿按钮/开关等控件回落到旧版扁平外观。对比 Chrome 是 `minos 13.0 / sdk 26.5`。修法：Package.swift 里 `xcrun --show-sdk-version` + `linkerSettings: [.unsafeFlags(["-Xlinker","-platform_version",...])]`，minos 保持 13.0、sdk 用真实版本。`vtool -show-build` 可验证。
- 验证手段：屏幕解锁时用 `screencapture -l<windowid>` / 全屏截图 + PIL 取像素做几何与配色核对；用自写 Swift `CGEvent` 工具（/tmp/clicker、/tmp/keyer）模拟点击与快捷键（注意 `lsappinfo front` 确认目标 App 在前台，否则事件落到别的窗口）。锁屏状态下 `screencapture` 只会拿到全黑图。
